## Run project
### Clone repo
```
git clone --recursive https://github.com/Faotik/3D-Cellular-Automata
```
### Build project
Project uses cmake so you can build it from terminal or any IDE that support it like Visual Studio or Clion
```
cmake -B build
cmake --build build
```
### Run executable
```
./debug/openglapp
```
